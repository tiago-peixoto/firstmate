# Issue 4228 live validation evidence

Every transcript was produced by running the real firstmate scripts from this change in a throwaway `FM_HOME`, with a real tmux server on a private socket standing in for the worker's pane (the pane runs `cat`, so anything typed into it shows up in the capture).

- `fm-send-automatic.transcript.txt` (`drive-fm-send-automatic.sh`): an automatic send to a worker with an open decision or blocker exits 4, records nothing and leaves the pane untouched; the deliberate answer still rings; open captain-hold and pending-reply keys do not defer; misuse of the flag is refused.
- `fm-send-status-shapes.transcript.txt` (`drive-fm-send-status-shapes.sh`): the same check across the status lines workers actually write (unkeyed, followed by `working:`, `paused:`, resolved, no status file).
- `fm-send-remote-automatic.transcript.txt` (`drive-fm-send-remote-automatic.sh`): a remote secondmate is deferred before any ssh transport is tried.
- `reconcile-deferral.transcript.txt` (`drive-reconcile-deferral.sh`): a queued reconcile request stays queued across passes with no fm-send spawn, exit 0 and no cooldown, and is delivered once the decision closes.
- `watcher-reconcile.transcript.txt` vs `watcher-reconcile.base.transcript.txt` (`drive-watcher-reconcile.sh`): the real `fm-watch.sh`, relaunched for 12 s. On the base commit it rings the waiting mate; on this change it does not, writes no triage line, and delivers the request after the answer.
- `bootstrap-nudge.transcript.txt` (`drive-bootstrap-nudge.sh`): the session-start re-read nudge is reported as `deferred:` and its marker is kept, then the retry is delivered after the answer.
- `config-push.transcript.txt` (`drive-config-push.sh`): a local config reread deferral exits 0 and keeps its retry, then the reread is sent after the answer.
- `pending-reply-recovery.transcript.txt` (`drive-pending-reply-recovery.sh`): the missed-report repost is held while the mate's own decision is open, and is not held by a relayed captain hold.
- `brief-{ship,scout,sm}.{base,head}.md` and `brief-*.diff`: the worker briefs generated by `bin/fm-brief.sh` on the base commit and on this change.
- `targeted-tests.txt`: the repository's own end-to-end cases for these paths, filtered to the relevant tests.

The bootstrap and config-push drivers source world builders from a copy of `tests/fm-secondmate-sync.test.sh` and `tests/fm-secondmate-harness.test.sh` with the test-case calls removed. Pass that copy as `HELPERS` and the checkout as `WT` to rerun them.
